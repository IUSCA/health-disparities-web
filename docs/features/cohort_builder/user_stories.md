**User Story 1: Build Queries Using Fields from Phenotype and Genotype Data**
- **As a** user
- **I want** to build queries using fields from phenotype and genotype data and combine them with logical operators such as AND, OR, and Exclude
- **So that** I can filter participants effectively

**Acceptance Criteria:**
- Users can see all available fields from the dataset
- Users can select fields grouped by category (demographic, lab, diagnosis, etc.)
- Users can use operators like equals, not equals, greater than, less than, and between for numeric fields
- Users can select options for categorical fields
- Users can select date ranges for date fields
- Users can combine multiple filters using AND, OR, and Exclude operators

**User Story 2: Execute Queries and View Results in Real-Time**
- **As a** user
- **I want** to execute queries and view the results in real-time
- **So that** I can quickly analyze the data

**Acceptance Criteria:**
- Users can execute queries
- Results are displayed in real-time
- Query performance is optimized for large datasets

**User Story 3: Support Query Versioning**
- **As a** user
- **I want** to track changes and revert to previous versions of queries

**Acceptance Criteria:**
- Users can save versions of queries
